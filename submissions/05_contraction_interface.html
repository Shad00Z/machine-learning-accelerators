Task 2: Generating a Basic Config

After creating our basic setup with the configuration parameters and the Config itself, we can now create a generate_config function. This generate_config function takes an einsum string and a list of shapes for the input tensors and returns a basic Config.

We broke the generation down to a four step procedure. The first step is to parse the einsum string to get output and input indices.

Step 1: Parse the einsum string
1    output_indices, input_indices_list = _parse_einsum(einsum_str)
2
3    if len(input_indices_list) != len(input_shapes):
4        raise ValueError(
5            f"Number of input tensors in einsum ({len(input_indices_list)}) "
6            f"does not match number of provided shapes ({len(input_shapes)})."
7        )

We make sure that the list of indices we retrieve from the einsum string matches with the input shapes that were handed to the generate_config function.

After the initial verification, we collect the dimension sizes and check for their consistency.

Step 2: Dimension index collection
 1    dim_sizes: dict[str, int] = {}
 2    # For each input tensor (list of indices) and its shape
 3    for indices, shape in zip(input_indices_list, input_shapes):
 4        # rank mismatch check
 5        if len(indices) != len(shape):
 6            raise ValueError(
 7                f"Input tensor with indices {''.join(indices)!r} has "
 8                f"{len(indices)} indices but shape {shape} has rank {len(shape)}."
 9            )
10        # For each input dimension index and its corresponding size
11        for idx, sz in zip(indices, shape):
12            if idx in dim_sizes and dim_sizes[idx] != sz:
13                # We already have a size for this dimension index, but it conflicts with the new one
14                raise ValueError(
15                    f"Conflicting sizes for dimension '{idx}': "
16                    f"{dim_sizes[idx]} vs {sz}."
17                )
18            dim_sizes[idx] = sz

The collection is performed tensor by tensor. First, each tensor’s indices and shapes are compared to rule out rank mismatches. Then, the single indices of the tensor are either added to the dim_sizes dictionary or an exception is raised, if an index already exists and it conflicts with the already existing dimension size.

With these dim_sizes we build the per-dimension attribute lists.

Step 3: Attribute list for dimensions
1    # Step 3: Build per-dimension attribute lists, one entry per key in dim_sizes
2    dim_types_list:  list[DimType]  = []
3    exec_types_list: list[ExecType] = []
4    sizes_list:      list[int]      = []
5    for idx, sz in dim_sizes.items():
6        dim_types_list.append(_classify_dim(idx, output_indices, input_indices_list))
7        exec_types_list.append(ExecType.SEQ)
8        sizes_list.append(sz)

To create an attribute list we iterate over our dim_sizes dictionary and classify each dimension.

Dimension classification
 1def _classify_dim(idx: str,
 2                  output_indices: list[str],
 3                  input_indices: list[list[str]]) -> DimType:
 4    """Classify a single dimension index.
 5
 6    Rules:
 7    - M: Appears in output and left input
 8    - N: Appears in output and right input
 9    - C: Appears in all tensors (both inputs + output)
10    - K: Appears in both inputs but not output
11    """
12    in_output = idx in output_indices
13    in_left = len(input_indices) > 0 and idx in input_indices[0]
14    in_right = len(input_indices) > 1 and idx in input_indices[1]
15
16    if in_output and in_left and in_right:
17        return DimType.C
18    if in_output and in_left:
19        return DimType.M
20    if in_output and in_right:
21        return DimType.N
22    if in_left and in_right:
23        return DimType.K
24    raise ValueError(
25        f"Cannot classify dimension '{idx}' in einsum expression.")

Dimension classification means we check in which tensors a dimension appears and according to that we classify the dimension. For this third step, we also assign each dimension the SEQ execution type.

In the fourth and final step we compute the strides for each tensor.

Step 4: Stride computation
1    all_tensor_indices: list[list[str]] = input_indices_list + [output_indices]
2    strides_list: list[list[int]] = [
3        _compute_row_major_strides(ti, list(dim_sizes.keys()), dim_sizes)
4        for ti in all_tensor_indices
5    ]

First of all, we assign each dimension that is not appearing inside a tensor the value 0. The calculation for the remaining dimensions is pretty straightforward.

Stride multiplication
 1def _compute_row_major_strides(indices: list[str],
 2                               dim_order: list[str],
 3                               dim_sizes: dict[str, int]) -> list[int]:
 4    """Compute row-major strides for a tensor whose axes are *indices*.
 5
 6    *dim_order* is the order of all dimensions in the Config.
 7    Returns a list of length ``len(dim_order)`` where dimensions not in
 8    *indices* get a stride of 0.
 9    """
10    # rightmost index gets stride 1
11    # then multiply by size as we move leftwards
12    tensor_strides: dict[str, int] = {}
13    stride = 1
14    for idx in reversed(indices):
15        tensor_strides[idx] = stride
16        stride *= dim_sizes[idx]
17
18    # 0 as default
19    return [tensor_strides.get(d, 0) for d in dim_order]

We start with the rightmost index for a tensor and assign the value 1. To calculate the strides we go from the rightmost to the leftmost index for each tensor. Afterwards we multiply the size of the respective tensor (e.g. the rightmost) with the current stride and thereby receive the stride for next dimension index.

Task 3: Optimizer Class

a) Split Dimensions

For the split_dim function we follow a number of steps to guarantee that the dimension split is performed correctly.

First we verify that the dimension that is supposed to be split is a valid dimension of our configuration and that \(outer\_size * inner\_size\) equals the original size.

Split dimension: Dimension verification
 1        cfg = self.config
 2        ndim = len(cfg.dim_sizes)
 3
 4        if not (0 <= dim_id < ndim):
 5            raise ValueError(f"dim_id {dim_id} out of range [0, {ndim})")
 6        if outer_size * inner_size != cfg.dim_sizes[dim_id]:
 7            raise ValueError(
 8                f"outer_size * inner_size = {outer_size} * {inner_size} = "
 9                f"{outer_size * inner_size} != dim_sizes[{dim_id}] = {cfg.dim_sizes[dim_id]}"
10            )

After the verification we replace the original dimension entry in the config object with the new inner and outer dimension.

Split dimension: Replacing the original entry
 1        # Replace the original entry with [outer, inner] at the same position.
 2        for per_dim, outer_val, inner_val in [
 3            (cfg.dim_types,  orig_type,   orig_type),
 4            (cfg.exec_types, orig_exec,   orig_exec),
 5            (cfg.dim_sizes,  outer_size,  inner_size),
 6        ]:
 7            # remove the original dim_id entry
 8            per_dim.pop(dim_id)
 9            per_dim.insert(dim_id, inner_val)  # inserts inner at dim_id
10            per_dim.insert(dim_id, outer_val)  # outer pushes inner to dim_id+1

The last step is to calculate the strides for the new dimensions and store them in the config object.

Split dimension: Stride calculation
 1        for t_strides in cfg.strides:
 2            orig_stride = t_strides.pop(dim_id)
 3            if orig_stride == 0:
 4                # Dimension was not in this tensor, so both new dims are also not in this tensor
 5                t_strides.insert(dim_id, 0)  # inner
 6                t_strides.insert(dim_id, 0)  # outer
 7            else:
 8                # Row-major: outer stride = orig * inner_size, inner = orig.
 9                t_strides.insert(dim_id, orig_stride)               # inner
10                t_strides.insert(dim_id, orig_stride * inner_size)  # outer

b) Fuse Dimensions

For the fuse_dim function we follow a similar approach.

As a first step, we verify again that the dimensions that are supposed to be fused are part of our config object.

Fuse dimensions: Dimension verification
1        cfg = self.config
2        ndim = len(cfg.dim_sizes)
3
4        if not (0 <= dim_id_a < ndim):
5            raise ValueError(f"dim_id_a {dim_id_a} out of range [0, {ndim})")
6        if not (0 <= dim_id_b < ndim):
7            raise ValueError(f"dim_id_b {dim_id_b} out of range [0, {ndim})")
8        if dim_id_a == dim_id_b:
9            raise ValueError("dim_id_a and dim_id_b must be different")

Next we check if the dimensions are placed contiguously in memory.

Fuse dimensions: Check continuity
 1        size_a = cfg.dim_sizes[dim_id_a]
 2        size_b = cfg.dim_sizes[dim_id_b]
 3
 4        # Step 1: check if the dims are contiguous in memory and have consistent relative order
 5        a_is_outer_dim = False
 6        b_is_outer_dim = False
 7        for tensor_id, strides in enumerate(cfg.strides):
 8            stride_a = strides[dim_id_a]
 9            stride_b = strides[dim_id_b]
10            if stride_a == 0 or stride_b == 0:
11                continue  # at least one dim is not in this tensor, so no contiguity requirement
12            if stride_a == stride_b * size_b:
13                a_is_outer_dim = True
14            elif stride_b == stride_a * size_a:
15                b_is_outer_dim = True
16            else:
17                raise ValueError(
18                    f"Dimensions {dim_id_a} (stride={stride_a}, size={size_a}) and "
19                    f"{dim_id_b} (stride={stride_b}, size={size_b}) are not "
20                    f"memory-contiguous in tensor {tensor_id}."
21                )
22        if a_is_outer_dim and b_is_outer_dim:
23            raise ValueError(
24                f"Dimensions {dim_id_a} and {dim_id_b} have inconsistent relative order "
25                f"across tensors: some tensors have {dim_id_a} as outer, others have "
26                f"{dim_id_b} as outer."
27            )

After this check we calculate the new stride for the fused dimension.

Fuse dimensions: Stride calculation
 1        # Step 2: update strides
 2        for strides in cfg.strides:
 3            stride_a = strides[dim_id_a]
 4            stride_b = strides[dim_id_b]
 5            if stride_a == 0 and stride_b == 0:
 6                new_stride = 0
 7            elif stride_a == 0:
 8                new_stride = stride_b
 9            elif stride_b == 0:
10                new_stride = stride_a
11            else:
12                new_stride = min(stride_a, stride_b)
13
14            strides[dim_id_a] = new_stride  # keep a
15            strides.pop(dim_id_b)          # remove b

Finally we store the fused dimension and the stride at the respective position and remove the previous indices.

Fuse dimensions: Storing the new dimension
1        # Step 3: update per-dimension lists
2        cfg.dim_sizes[dim_id_a] = size_a * size_b
3        # remove dim_id_b entries (keep dim_id_a's type and exec)
4        cfg.dim_sizes.pop(dim_id_b)
5        cfg.dim_types.pop(dim_id_b)
6        cfg.exec_types.pop(dim_id_b)

c) Permute Dimensions

Our permute_dims function follows the syntax of the torch.permute function. That means the i-th entry of the result comes from the position permutation[i] in the original.

Permute dimensions
 1    def permute_dims(self, permutation: list[int]):
 2        """Reorder all per-dimension lists according to *permutation*.
 3
 4        Follows torch.permute semantics: the i-th entry of the result comes
 5        from position permutation[i] in the original.
 6        """
 7        cfg = self.config
 8        ndim = len(cfg.dim_sizes)
 9
10        # Check that permutation is valid
11        if sorted(permutation) != list(range(ndim)):
12            raise ValueError(
13                f"permutation must be a permutation of [0, {ndim}), got {permutation}"
14            )
15
16        # Reorder all per-dimension lists according to the permutation
17        cfg.dim_types = [cfg.dim_types[i] for i in permutation]
18        cfg.exec_types = [cfg.exec_types[i] for i in permutation]
19        cfg.dim_sizes = [cfg.dim_sizes[i] for i in permutation]
20        cfg.strides = [[t[i] for i in permutation] for t in cfg.strides]

d) Execution

The make_executable function assigns execution types and permutes the dimensions of the config object. We distinguish three types of execution types: PRIM, PAR, and SEQ.

By default each dimension is assigned the SEQ execution type. For the PRIM execution type we select the dimension with the smallest non-zero stride for each tensor. We select a dimension for each of the dimension types M, N, and K.

Exec types: PRIM selection
 1        def _pick_prim(dim_type: DimType, tensor_idx: int) -> int:
 2            """Picks the candidate with the smallest non-zero stride in tensor *tensor_idx*.
 3            """
 4            best_idx = -1
 5            best_stride = float("inf")
 6            for i, dt in enumerate(cfg.dim_types):
 7                if dt != dim_type:
 8                    # wrong dim_type, skip
 9                    continue
10                stride = cfg.strides[tensor_idx][i]
11                if 0 < stride < best_stride:
12                    best_stride = stride
13                    best_idx = i
14            if best_idx == -1:
15                raise ValueError(
16                    f"No {dim_type.value} dimension found in config.")
17            return best_idx
18
19        # Step 2: assign PRIM dims based on the picking strategy
20        prim_m = _pick_prim(DimType.M, 0)  # input 0 for M
21        prim_n = _pick_prim(DimType.N, 1)  # input 1 for N
22        prim_k = _pick_prim(DimType.K, 0)  # input 0 for K
23        prim_set = {prim_m, prim_n, prim_k}

After assigning the PRIM execution types, we once again loop over all dimensions and change all dimensions to a PAR execution type that aren’t of dimension type K.

Exec types: PAR assignments
1        # Step 3: assign exec types

4                cfg.exec_types[i] = ExecType.PRIM
5            elif dt != DimType.K:
6                # M, N, C dims that are not PRIM can be PAR
7                cfg.exec_types[i] = ExecType.PAR
8            # else: remaining K dims stay SEQ

The last step is to move the SEQ dimensions to the leftmost positions and the PRIM dimensions to the rightmost positions. We verify the new execution types with the verify function.

Exec types: SEQ and PRIM reordering

5            cfg.exec_types) if e == ExecType.SEQ]

First, we verify that no dimension of type K has the PAR execution type assigned.

Task 4: L2-Optimized Batched Contraction

a) Initial Config

For the batched matrix multiplication cmk, ckn -> cmn our generate_config function from Task 2 produces the following config:

Config(
    data_type  = DataType.FLOAT16
    prim_main  = PrimType.GEMM
    prim_last  = LastType.NONE
    prim_first = FirstType.ZERO
    dim_types  = ['C', 'M', 'K', 'N']
    exec_types = ['SEQ', 'SEQ', 'SEQ', 'SEQ']
    dim_sizes  = [4, 4096, 4096, 4096]
    strides[0] = [16777216, 4096, 1, 0]
    strides[1] = [16777216, 0, 4096, 1]
    strides[2] = [16777216, 4096, 0, 1]
)

b) Optimized Config

To optimize the initial config object we made five transformations.

First, we split the N dimension into n1=4 and n2=1024. Second, we split the M dimension into m1=4 and m2=1024. To incorporate the tile sizes directly into the configuration, we additionally split the three PRIM dimensions: the M inner dimension (1024) into (16, tM=64), the K dimension (4096) into (64, tK=64), and the N inner dimension (1024) into (16, tN=64). After calling make_executable(), the PRIM dimensions carry exactly the tile sizes, so no separate heuristic is needed to derive them.

We decided to go with n2=m2=1024 because with these dimensions we use the L2 cache optimally. After this dimension splitting we have 4194304 bytes left in the L2 cache. With a bigger dimension size we would not be able to keep the whole computation within the L2 cache.

Config(
  data_type  = DataType.FLOAT16
  prim_main  = PrimType.GEMM
  prim_last  = LastType.NONE
  prim_first = FirstType.ZERO
  dim_types  = ['C', 'M', 'M', 'N', 'N', 'K', 'M', 'K', 'N']
  exec_types = ['PAR', 'PAR', 'PAR', 'PAR', 'PAR', 'SEQ', 'PRIM', 'PRIM', 'PRIM']
  dim_sizes  = [4, 4, 16, 4, 16, 64, 64, 64, 64]
  strides[0] = [16777216, 4194304, 262144, 0, 0, 64, 4096, 1, 0]
  strides[1] = [16777216, 0, 0, 1024, 64, 262144, 0, 4096, 1]
  strides[2] = [16777216, 4194304, 262144, 1024, 64, 0, 4096, 0, 1]
)

c) Optimized Kernel

The kernel that executes this optimized config object for the initial batched matrix multiplication cmk, ckn -> cmn consists of two parts:

  1. a launch function,

  2. the kernel itself.

The launch kernel creates the grid according to the output tensor c * m1 * n1 * m2 * n2 and forwards all the data to the kernel:

Launch function
 1def launch_optimized_config_kernel(A, B, C, tM, tN, tK, m_prim_size, n_prim_size):
 2    m_prim_tiles = ct.cdiv(m_prim_size, tM)
 3    n_prim_tiles = ct.cdiv(n_prim_size, tN)
 4    m_par_count  = ct.cdiv(C.shape[1], m_prim_size)
 5    n_par_count  = ct.cdiv(C.shape[2], n_prim_size)
 6
 7    grid = (C.shape[0] * m_par_count * n_par_count * m_prim_tiles * n_prim_tiles, 1, 1)
 8
 9    ct.launch(torch.cuda.current_stream(), 
10              grid, 
11              optimized_config_kernel,
12              (A, B, C, tM, tN, tK, m_prim_size, n_prim_size))
13    return

The kernel itself calculates the block IDs according to the shape of the output tensor.

 1    bid = ct.bid(0)
 2
 3    n1 = bid % ct.cdiv(n_in_size, tN)
 4    bid = bid // ct.cdiv(n_in_size, tN)   # tile within n_in group
 5    
 6    m1 = bid % ct.cdiv(m_in_size, tM)
 7    bid = bid // ct.cdiv(m_in_size, tM)   # tile within m_in group
 8    
 9    n2 = bid % ct.cdiv(C.shape[2], n_in_size)
10    bid = bid // ct.cdiv(C.shape[2], n_in_size)  # n L2 group
11    
12    m2 = bid % ct.cdiv(C.shape[1], m_in_size)
13    bid = bid // ct.cdiv(C.shape[1], m_in_size)  # m L2 group
14    
15    c  = bid

Then we load the tiles and calculate our batched matrix multiplication.

Batched Matrix Multiplication
 1    # combine L2 group and tile within L2 group to get global tile index
 2    m_tile = m2 * ct.cdiv(m_in_size, tM) + m1
 3    n_tile = n2 * ct.cdiv(n_in_size, tN) + n1
 4
 5    acc = ct.zeros((tM, tN), dtype=torch.float32)
 6
 7    for k in range(ct.cdiv(A.shape[2], tK)):
 8        tile_A = ct.load(A, index=(c, m_tile, k), shape=(1, tM, tK), padding_mode=ct.PaddingMode.ZERO)
 9        tile_B = ct.load(B, index=(c, k, n_tile), shape=(1, tK, tN), padding_mode=ct.PaddingMode.ZERO)
10        
11        acc = ct.mma(ct.reshape(tile_A, (tM, tK)), ct.reshape(tile_B, (tK, tN)), acc)
